ALBUMS
======
Every folder you put in here becomes an album.  Name the folder like the album, put the songs
(mp3, ogg, flac, wav, opus) inside it, e.g.

   albums\I Want To Die In New Orleans\01 - Song.mp3
   albums\I Want To Die In New Orleans\02 - Other Song.mp3
   albums\Kill Yourself Part III\...

In the game each folder is an item "album: <folder name>" that weighs nothing.  Zombies sometimes
carry one.  While you carry it, use an mp3 player and pick "Choose album" to listen to it.
Choose "Normal playlist" to go back to the songs in the game's "music" folder.

- Songs are shuffled.  Put an empty file called noshuffle.txt into an album folder to play it in order.
- New folders show up the next time the game loads.  Do not delete or rename a folder that a save
  still uses, or its album item disappears from that save.
- Folders without audio files are ignored.
